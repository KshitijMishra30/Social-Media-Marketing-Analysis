# Social Media Marketing Campaign Analysis

## Overview
A Power BI project for exploring social media marketing campaign performance through an interactive dashboard.

## Dashboard focus
Based on the project brief, the dashboard is intended to help review campaign performance and marketing metrics such as advertising spend, conversions, revenue/ROI, customer acquisition cost, platform and audience segments. Refer to the report pages and measures in the PBIX for the exact metrics and definitions used.

## Tools
Microsoft Power BI Desktop, Power Query, DAX, Data Visualization.

## Files
- `Social_Media_Marketing.pbix` – Power BI report file.

## How to view
1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Download this repository.
3. Open `Social_Media_Marketing.pbix` in Power BI Desktop.
4. If prompted, update data-source paths or credentials to match your local files, then refresh the report.

## Data note
The PBIX may rely on source data files or connections that are not included here. Add only datasets you have permission to redistribute. If the report uses local file paths, update them in Power Query before sharing.
